# Personalizing Text-to-Image Diffusion Models

Jupyter Notebook developed for the **Neural Network** university exam.

The project explores the fine-tuning of pre-trained text-to-image diffusion models for **subject-driven generation**, allowing the model to generate images of a specific user-provided concept (e.g., a particular object or pet) from text prompts.

The project is based on and compares two approaches for personalizing text-to-image diffusion models:

* **Custom Diffusion** — Nupur Kumari, Bingliang Zhang, Richard Zhang, Eli Shechtman, Jun-Yan Zhu. *Multi-Concept Customization of Text-to-Image Diffusion*. CVPR 2023. [[Paper](https://arxiv.org/abs/2212.04488)]
* **DreamBooth** — Nataniel Ruiz, Yuanzhen Li, Varun Jampani, Yael Pritch, Michael Rubinstein, Kfir Aberman. *DreamBooth: Fine Tuning Text-to-Image Diffusion Models for Subject-Driven Generation*. CVPR 2023. [[Paper](https://arxiv.org/abs/2208.12242)]

The notebook contains the complete project, including the theoretical background, implementation details, experimental setup, results, and discussion.
